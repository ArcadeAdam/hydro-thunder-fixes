# Security reports

For a suspected vulnerability in this project's installers, helper, or source,
use this repository's **Security -> Advisories -> Report a vulnerability** form
on GitHub. Private vulnerability reporting is enabled for this repository.
Do not disclose exploitable details, credentials, or personal data in a public
issue. Ordinary rendering, control, or compatibility problems belong in Issues.

Include the affected release, a description of the impact, and minimal steps
to reproduce using synthetic data where possible. Do not attach game binaries,
private runtime/account configurations, real score files, or access tokens.
There is no guaranteed response deadline; this is a community-maintained project.

Install official project ZIPs from this repository's Releases page and verify
the accompanying checksum. Checksums detect a changed or incomplete download;
they are not a code-signing certificate or a promise that software has no bugs.
Keep score backups and close the game before installing or uninstalling.

Fixes are published as new versioned releases. Existing release assets remain
available so changes can be reviewed and earlier behavior reproduced.
